# Local Browser OCR with Tesseract.js

This example demonstrates how to perform Optical Character Recognition (OCR) directly within your web browser using Tesseract.js. It allows users to select an image file, and the text recognition process runs entirely client-side, ensuring privacy and local processing, as highlighted in the accompanying article. The recognized text is then displayed on the page.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in a modern web browser (e.g., Chrome, Firefox).
3. Select an image file using the 'Choose File' button and click 'Recognize Text'.
